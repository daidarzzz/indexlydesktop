Features

What is Indexly?

Indexly is a universal catalog search engine and personal indexing vault. It eliminates wasted time hunting across scattered disks, folders, and dumps by organizing everything into an instant offline index.

Universal Catalog Ingestion

Bring game libraries, movie lists, digital books, music collections, CSV files, and magnet link dumps into a single searchable dashboard.

.json.csv.tsv.txtenvelope v2magnet:

Sub-millisecond Search (< 0.5 ms)

Native Rust engine with SQLite FTS5, diacritics removal, and BM25 relevance ranking. Find any item out of hundreds of thousands instantly.

100% Local-First & Zero WAN Telemetry

Your catalogs live in an open SQLite database on your machine. 0 bytes are transmitted to remote servers. No subscriptions, no ads, no cloud lock-in.

Auto-Mapping & Flexible Envelopes

Drop any JSON, CSV, or v2 envelope. Indexly automatically identifies title, download URI, and size fields with zero configuration needed.

Indexly Hub & Obsidian-Style Plugins

Connect pre-built catalog packages from Indexly Hub or install community plugins (GameVault, ReadLy, grid views) via @indexly/plugin-api.

Architecture

Local-First Architecture

Cloud databases enforce 400ms network round-trips and recurring fees to access your own collection records. Indexly indexes millions of items locally with Rust for instant access.

  • RustNative core with Tauri v2
  • FTS5BM25 ranking & diacritics removal
  • .dbOne open SQLite file you own
sqlite_catalog_vault.sql RUST + FTS5 
-- Unified Catalog Storage (Indexly SQLite FTS5)
CREATE VIRTUAL TABLE catalog_vault USING fts5(
    id UNINDEXED,
    source_name UNINDEXED,
    title,
    subtitle,
    file_size UNINDEXED,
    link UNINDEXED,
    tokenize = 'unicode61 remove_diacritics 2'
);

-- Instant lookup across 500,000+ items (< 0.5ms)
SELECT title, subtitle, file_size, link, bm25(catalog_vault) AS rank
FROM catalog_vault
WHERE catalog_vault MATCH 'cyberpunk OR matrix'
ORDER BY rank
LIMIT 50;

FAQ

Frequently Asked Questions

What kinds of catalogs can I search with Indexly?

Anything you can catalog: game collections, movies and series, digital books, music discographies, dataset dumps, software releases, or torrent and magnet lists. You can import standard JSON arrays, CSV spreadsheets, or Indexly v2 envelope packages.

How fast is the search across large collections?

Indexly uses SQLite Full-Text Search (FTS5) compiled in native C++ and managed through Rust. Even with 500,000+ indexed items, queries return in under 0.5 milliseconds directly from local memory and SSD cache.

Does Indexly upload my library data to the cloud?

Never. Indexly operates entirely offline on your computer. All indexes, configurations, and source mappings are saved in an open SQLite database inside your local app data folder. Zero telemetry packets leave your machine.

What is Indexly Hub?

Indexly Hub is a decentralized repository explorer integrated into the desktop app that allows you to discover, download, and sync pre-mapped catalog packages curated by the community with one click.
